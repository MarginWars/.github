# The Margin Wars: organisation defaults

Default community health files for every repository in the [MarginWars](https://github.com/MarginWars)
organisation, and the organisation profile in [`profile/README.md`](profile/README.md). A repository that has its
own copy of a file (for example [themarginwars](https://github.com/MarginWars/themarginwars)) uses its own.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organisation profile at [github.com/MarginWars](https://github.com/MarginWars) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How changes are proposed, reviewed and merged |
| [`SECURITY.md`](SECURITY.md) | How to report a security or privacy problem |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`.github/`](.github) | Default issue forms and pull request template |

Brand assets in `profile/assets/` are rendered from the site's fonts and tokens in
[themarginwars/.github/assets/src](https://github.com/MarginWars/themarginwars/tree/main/.github/assets/src).
