# Security and privacy

MarginWars repositories are public. Treat every byte as published.

## Reporting a problem

If you find a secret, a token or personal data in a MarginWars repository, or a security problem on
[themarginwars.com](https://themarginwars.com):

- **Do not open a public issue or pull request.**
- Email [hello@themarginwars.com](mailto:hello@themarginwars.com) with the subject line "Security" and the
  repository, file or page.

We rotate any exposed secret first, then remove it from history.

## What never goes in a repository

- Secrets of any kind: API tokens, webhook URLs, passwords, private keys, session cookies.
- Personal data: phone numbers, home addresses, personal email addresses, lead or contact-form records.
- Private or internal material: private notes, unpublished personal facts, QA screenshots.
